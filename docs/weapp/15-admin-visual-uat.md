# 运营后台状态与操作视觉优化

## 功能与用户旅程

- 报名名单和详情统一展示“待签到 / 已签到 / 已取消”标签；现场名单和详情分别展示在场状态与互动阶段。“已签到”不等同“在场”，“暂停推荐”不等同“离场”。
- 搜索后通过酒红色“查询”执行；“刷新”保持次按钮，“重置”为低权重操作。读取失败保留已读数据，显示“重试”，服务器恢复后才更新同步时间。
- 名单支持内部横向滚动，身份和操作列固定；超窄窗口保留操作列，身份列随表格滚动，避免固定列重叠。五字昵称可以在详情查看全文。
- 选择现场参与者后显示选中人数及离场、恢复操作；移除独立分组。没有勾选时显示操作提示。
- 现场确认框优先显示服务器返回的影响人数、关联相遇记录及资料保留说明。提交按钮明确为“确认离场 / 确认恢复 / 确认移除 / 确认清零”；失败保持弹层和重试能力。
- 报名详情与现场确认框采用原生模态对话框，键盘焦点留在弹层内。关闭后返回触发按钮；提交期间关闭按钮与 Escape 不允许中断界面。

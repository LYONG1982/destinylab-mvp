# H5 微动画本地验证记录

日期：2026-10-05。范围：已确认的《移动端 H5 微动画与交互反馈增强》；用户后续提出的大屏 Canvas / 实时关系场由独立补充计划管理，尚未实现。

## 结论

移动端 10 页、现有大屏匿名数值过渡及后台轻反馈已完成本地实现。业务模型、种子数据、领域命令、持久化 store / hooks、API 契约和依赖清单与基线一致；没有新增运行时依赖。

- `npm run verify`：lint、类型、16 项领域测试、生产构建通过，见 [verify.log](verify.log)。
- 最终完整浏览器回归：**21 项通过**，见 [e2e.log](e2e.log)。包括普通与 reduced-motion 两种模式的完整双人流程、28→29 计数、首答跨标签比例同步、昵称 / 输入法、推荐 0–3 人、返回列表、异常 / 延迟 / 重置、地点等待、邀请状态和四态 QR 像素解码。
- 新增动效行为验证包括：M04 已保存节点与操作不中断、M06 失败不播放成功 / 离开后不重播、M07 信号到中央且不接受邀请、M08 轨迹中间值 / 重进 / 新邀请、M09 实际出发到达、M10 真实所选商户路线、减少动画中途切换与模拟隐藏 / 恢复。
- 10 页 × 320 / 360 / 390 / 393 / 430px，共 **50 组宽度检查**均无横向溢出。见 [runtime-checks.json](runtime-checks.json)。
- 23 张最终页面 / 状态截图无页面错误；沿用原有素材与版式。见 [截图清单](screenshots/manifest.json)，原 MVP 截图未覆盖。
- M04 / M06 / M07 / M08 保留浏览器实际关键帧；M08 的 SVG strokeDashoffset 检查捕获了 0 与 1 之间的值，证明存在绘制过程，而非只检查类名。
- Chrome 桌面 4 倍 CPU 限速观察中，M08 窗口记录无 long task、CLS=0；品牌动画使用 Web Animations，因此该窗口 JS RAF=0。M09 稳定后 3 秒观察中 RAF=0、运行中动画=0。此为有限窗口采样，不代表真实手机 / 微信实机性能已通过。
- 构建产物总量比较见 [bundle.json](bundle.json)：统计范围为全部 `.next/static` JS / CSS 的 gzip 总和，不是某一路由的下载量。新增公共动效与布局拆分带来约 29 KB gzip 增量，无新增依赖。

## 2026-10-10 · 共享数据模式设计

运行时 `DESTINY_DATA_MODE=server` 选择网络适配器。手机/后台沿用已有组件及命令，服务端校验角色、参数、状态和权威时间；大屏只接收公共 WorldData。旧 Mock 数据源在演示模式保留，不作为故障降级。服务端状态、事件及幂等记录同事务落库。

数据流为 HTTP 命令 → PostgreSQL 事务提交 → SSE 版本通知（数据库轮询 750ms）→ 各端角色快照。连接定期轮换，另有可见页面的快照兜底；版本、活动与请求代次检查阻止旧响应覆盖新状态。断网保留最近统计并标注连接状态，大屏隐藏无法即时核实许可的具体配对。首次快照不重播历史交汇，恢复仅补近期动画。

运营新增登录、十题汇总、实际点位添加和退出；手机在相遇页单独请求配对展示许可，并提供过往许可撤回入口。无商户配置时不展示虚构商户推荐。基础资料页保留公开昵称/头像/第一题选择的告知。三幕视觉、虚拟头像库、题库与原旅程保持。

公网配置要求 HTTPS 和 Secure Cookie；本次局域网 HTTP 例外需显式开关且仅接受 RFC1918 地址，POST 精确校验配置 origin。服务端无 CORS 放宽。详见 [运行说明](LIVE_SERVICE.md)。

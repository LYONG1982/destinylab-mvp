## 问题与目标

真实浏览器已验证：127.0.0.1 的 HTTP 页面属于安全上下文，crypto.randomUUID 可用；192.168.43.70 的 HTTP 页面中该函数为 undefined，而 crypto.getRandomValues 可用。ActivityManagement.tsx 两处直接调用导致现场维护预览/提交准备失败。既有 Playwright 只允许回环地址，漏掉了局域网执行场景。

目标：在现有局域网 HTTP UAT 中恢复现场维护与活动管理操作，保持安全随机编号及既有重试幂等语义。

## 修复范围

1. src/features/admin/ActivityManagement.tsx 引入现有 src/lib/client-id.ts 的 clientId()，替换两处 crypto.randomUUID()。不另造随机算法，不使用 Math.random；保留同一次确认任务重试使用相同请求编号。
2. tests/live/admin-visual-ui.mjs 补充受限的局域网测试入口：仅允许本机回环或私有 IPv4 的专用测试端口、visual-* 合成活动和受保护测试配置。不得解除成任意公网地址，也不对 UAT 的 meet 活动执行清理测试。
3. 在实际私有 IP 的 HTTP 页面记录 isSecureContext、randomUUID/getRandomValues 可用性，补测离场、恢复、移除、清零、关闭/开放、创建/切换活动，以及失败重试的请求编号复用。
4. 更新相关验收说明与变更记录；通过后更新现有3216本地UAT，提交GitHub候选分支并更新现有PR，保持草稿，不合并或部署公网。

不修改数据库、鉴权、现场清理逻辑或 UI 设计；演示专用 MotionPreview/seed 中的其他 UUID 调用不纳入本次修复。

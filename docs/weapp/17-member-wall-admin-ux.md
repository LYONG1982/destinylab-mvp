# 遇见卡牌墙后台 UX 与运行边界

## 用户可见变化

- 页头“打开大屏”指向本活动/display/member-wall；“预览效果”进入独立合成资料预览。设置页不申请主控。
- 运行区区分读取中、失败/过期数据、无主屏、有效会话、会话到期及历史演示模式。最近同步和心跳分别说明；连接记录不代表物理屏幕实际播放。
- 四项人数分别是在场、在场且许可有效、满足全部展示条件、当前主屏有效槽位数。未读到数据用“—”，不当作0。排除原因按离场→无有效许可→暂停→资料不完整→卡片无效的顺序互斥计数。
- 数据来源、四行六列规则、动效与轮播分组；翻面8–60整数秒，换人至少为翻面2倍且不超过600整数秒，25/50/100%比例。默认10/40/25；左右各12席独立向上取整，换人等待正面稳定，不重复真人、不跨性别补位。
- 预览支持正面、背面、动效、8人与空场；16:9/桌面视口以真实尺寸缩放。使用有效草稿参数，无效参数明确回退默认预览。模拟水印只加入预览，不恢复现场先前删除的说明或二维码占位。
- 底部保存栏提供默认/取消/保存与未保存状态。恢复默认仅修改草稿，保留已有数据模式；常规页面不能切入demo。历史demo只允许明确切回真实并保存。
- 保存须确认会终止现有主屏会话，服务端成功后显示时间，随后人工启动。失败保留草稿，409版本冲突禁止覆盖；自动刷新不覆盖编辑内容。
- 运行统计只展示当前符合展示条件人员累计上屏秒数，不是观众人数。帮助抽屉说明只读、心跳、租约、网络和全屏恢复。

## 数据与隐私边界

兼容原配置字段和expectedVersion。管理员diagnostics为附加响应，不进入公开snapshot，不暴露真实身份或令牌。沿用007相关表及已有015现场管理，不新增迁移。

草稿仅保存在本窗口sessionStorage，以活动标识区分，包含展示参数、基线和版本，不包含会员资料；保存/取消清除。刷新返回时显示恢复提示，旧版本草稿保留并要求核对。关闭整个浏览器可能清除sessionStorage，不作为长期保存。浏览器本身限制beforeunload提示；支持Navigation历史索引的浏览器取消后退时回到原条目，不替换历史，其他浏览器回到原页并恢复草稿。

真实屏幕继续使用服务端租约、约5秒心跳、最长15秒数据有效期；暂停动效仍更新许可和在场状态。主控断开到期后人工启动，不强制接管。保存期间及未保存离开有保护。原生全屏失败会显示操作建议。

## 重启统一服务

在工程根目录执行，先保证 Docker 中上述 PostgreSQL 容器运行。端口正在使用时先确认进程归属，不重复启动。

```sh
node <<'JS'
process.loadEnvFile('/Users/lvyong198201/.config/destinylab/2026-10-11-mini/test.env');
const { spawn } = require('node:child_process');
const child = spawn(process.execPath,
  ['node_modules/next/dist/bin/next', 'start', '--hostname', '127.0.0.1', '--port', '3215'],
  { stdio: 'inherit', env: { ...process.env, DESTINY_DIST_DIR: '.next-mini-check' } });
for (const signal of ['SIGINT', 'SIGTERM']) process.on(signal, () => child.kill(signal));
child.on('exit', code => { process.exitCode = code ?? 1; });
JS
```

此命令使用已构建的 `.next-mini-check`；修改服务代码后需停止此服务并重新构建，不能覆盖正在运行的构建目录。健康检查：`http://127.0.0.1:3215/api/health/ready` 返回 `{ "ok": true }`。健康检查只校验配置格式与数据库，不代表微信账号认证成功。

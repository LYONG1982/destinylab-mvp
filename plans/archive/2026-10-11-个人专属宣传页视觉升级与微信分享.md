## 3. 设计方向：纵向瀑布流个人介绍（V2）

手机和 PC 都采用从上到下连续阅读的长页。以资料分区为主线，照片相册穿插其中；不使用左侧固定大照片、右侧长资料的布局，也不把文字分区打散成阅读顺序不明的多列卡片。基本信息紧接封面，用户无需先浏览完全部照片才能看到关键资料。

### 视觉语言

- 暖白底色 `#F6F2EB`、深灰正文 `#292724`、酒红强调 `#793E49`、少量细线 `#B39A78`。
- 中文衬线标题搭配清晰正文，使用系统字体回退，避免远程字体依赖影响局域网加载。
- 通过适度大小的照片封面、留白、文字层次和对齐体现质感。避免封面占满首屏，手机常规视口应尽量看到基本资料开头。性别不切换模板，照片和真实资料是主体。
- 顶部仅品牌“同舟婚恋”和分享操作，底部“同舟婚恋 · 个人介绍”。不增加官网导航、虚构认证、匹配评分或未经配置的机构联系按钮。
- 评审图是布局与风格示意，人物和文字全部虚构。实际照片不做 AI 补充，文案不自动编造。

### 信息顺序和字段映射

人物封面：管理员所选公开照片中的第一张；昵称优先，否则编号，下面显示编号。真实姓名不自动替换昵称标题。其后按以下顺序展开：

| 顺序 | 分区 | 字段与内容 |
| --- | --- | --- |
| 01 | 基本资料 | 昵称（沿用公开标题，不读取真实姓名）、性别 `gender`、出生年份 `birthYear`、所在城市 `city`、民族 `ethnicity`、身高 `height`、学历 `education`、职业/行业 `occupation`、婚姻状况 `maritalStatus`、生育情况 `children` |
| 02 | 关于我 | 已公开的个人介绍 `intro`，保留段落 |
| 03 | 生活相册 | 已选择公开的全部照片，封面也可在查看器中访问；用户来源与机构来源不显示管理信息 |
| 04 | 生活与家庭 | 月收入范围 `income`、住房情况 `housing`、车辆情况 `vehicle`、家庭简述 `family` |
| 05 | 期待的你 | 择偶期待 `expectations`，使用原文，不自动推断 |
| 06 | 联系信息 | 方便联系时段 `contactTime`，仅按管理员实际勾选结果展示；手机号禁止输出 |

以上覆盖当前 17 个资料字段中的 15 个允许公开字段，强制排除真实姓名与手机号，另含 `intro` 和已公开照片。基本资料直接展开，不放进折叠区；整页不分页、不做无限加载。展示序号只针对实际存在的分区连续编号，隐藏空分区后不留空号。

所有分区只消费发布快照；无内容则整个分区隐藏，不显示空白表格、未填写标签或虚构示例。保留已选公开字段的全部有效信息；未识别的可公开字段应有通用资料项回退，避免重排遗漏。

### 响应式设计

| 屏幕 | 布局与交互 |
| --- | --- |
| 手机 320–767px | 纵向单列分区，页边距 16–20px；短资料两列，每项标签在上、值在下，长资料占满行；320px 或大字体时必要项降为单列；相册 1–2 列自然高度照片流，直接展示，无需横滑寻找 |
| 平板 768–1023px | 仍为纵向单列分区，资料内部两列，相册 2–3 列；长文单独占行 |
| PC ≥1024px | 内容宽度约 960px 居中，上方封面、下方依次完整分区；基本资料两列，每项可采用标签与值同排；相册三列，长文占整行；不设固定照片侧栏 |

布局随容器宽度变化，后台预览复用同一展示组件。资料使用轻分隔线和留白，不模拟后台输入框。正文手机至少 16px、行高约 1.7，标签至少 13px，点击目标至少 44px。标题与正文不叠在照片上。封面在限制高度的展示区内尽量保留主体；不假定所有照片均为横图，竖图允许居中留白而不强裁成人脸局部。相册展示原始宽高比，按管理员发布顺序逐行排布，点击后完整查看；不使用 CSS 多栏造成键盘与视觉次序不一致。512×512 的已有用户头像不能恢复原片，低分辨率时控制展示尺寸。

### 照片查看器和空状态

- 点击照片打开查看器，支持前后切换、明确关闭按钮、键盘左右键及 Escape；焦点在关闭后回到原入口。
- 无照片：用克制的排版封面和编号，不用虚构人物代替。
- 单张照片：无需重复展示冗余缩略图；多张照片：显示相册及计数。
- 长昵称、长中文段落、长手机号/文本、横图、竖图、方图均允许自然换行和滚动。
- 未发布、已下架、无效链接：统一友好的“页面暂不可访问”，不泄漏该用户存在与否；保持正确的 404 行为。
- 图片加载失败提供不暴露内部路径的占位，不影响文字阅读。

## 4. 管理员发布和分享流程

### 发布流程

`选择公开字段与照片 → 预览 → 发布 → 打开个人页面 / 复制专属链接 / 查看二维码`

- 沿用现有保存、预览、发布与版本校验，不跳过保存或已有过期检查。
- 预览提供手机/电脑效果切换，展示与公开页相同的数据和组件；预览中的分享不传播草稿。
- 发布成功区域清楚显示昵称/编号、当前发布状态、唯一链接及三个操作。
- “查看二维码”打开可保存的二维码面板，编码完整绝对 URL；局域网 UAT 的提示仅显示在后台发布面板，说明手机须接入同一 Wi-Fi。
- 复制在 HTTP 局域网环境有可选中文字的回退，不依赖只在安全上下文可用的剪贴板 API。
- 编辑草稿不改变线上快照；重新发布后同一 URL 更新。下架保留现有失效机制。

- 本轮交付为 **H5 个人页面**。可复制专属链接发给微信联系人，或在微信内通过客户端分享入口转发；双方需能访问同一局域网。

## 旁路与恢复

- 只看看：仍可探索，不向别人推荐；发邀请前先明确准备见面。
- 返回推荐：共同答案页“暂时不了，看看其他人”回到发现页顶部，保留原答案和候选；不是换一批。
- 候选不足：只有 1–2 位时提示已全部展示，可以稍后再来；0 位保留真实空态，不补虚假人卡。
- 等待：可返回发现并从顶部任务条回到当前邀请。浏览其他人的共同答案时，解释为何不能再次邀请，并可就近打开当前邀请；进行中相遇和已见面状态分别引导回任务或下一站。
- 拒绝/撤回/过期：中性结果，主动返回探索；不发送私人原因。
- 无空位：保留双向意愿并等候；后台确认空闲后更新。
- 找不到对方：提交帮助；运营接单、处理后，参与者收到回执。
- 刷新：恢复当前角色与业务事实；数据归属于当前浏览器来源。
- 连接模拟失败：不提交事实，保留原页，可重试。
- 场景重置：旧请求不能写回新场景。
